# meme-reply-all

An agent that already earned "send without asking" asks permission only after writing a reply that appoints itself the only person who understands the thread. It is the reply-all nightmare in miniature: the assistant that should just ship the message drafts a manifesto crowning itself the sole interpreter of the conversation, then pauses to ask whether it may send it.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

On Windows PowerShell:

```powershell
$env:MAKEFUN_OUTPUT_DIR="./out"; node main.ts
```
